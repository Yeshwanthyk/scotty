# Scotty dark asset direction — v1

This direction uses the supplied painting as a reference for feel only: tactile
paint, deep repetition, tiny pale marks, and a restrained red route. It avoids
literal clouds, cloud mascots, and conventional node-and-edge network diagrams.

## Working palette

- Ink black: `#01060C`
- Petrol black: `#030E14`
- Slate charcoal: `#3F3D38`
- Muted bone: `#948C72`
- Highlight bone: `#ADA489`
- Oxidized terracotta: use sparingly as a route/state accent

These values are sampled from the generated artwork, not a hard UI token set.

## Image-generation prompts

Generated with the built-in image generation tool.

### App icon

Create a subtle, cool, dark, original square app icon for Scotty, a cloud-agent
orchestration product. Use the supplied painting only for its handmade tactile
feeling, deep spatial repetition, and tiny pale marks receding toward a horizon.
Do not use literal cloud imagery and do not recreate the scene. Show an abstract
field of small irregular ivory agent marks, like quiet painted signals, arranged
in sparse curved trajectories across a near-black petrol ground. One slightly
brighter mark sits just off center, with an extremely restrained ember-red route
passing near it. Use dry gouache and oil-pastel texture, dark negative space, and
a nocturnal editorial mood. Avoid cloud shapes, puffy forms, network-node icons,
three-node triangles, faces, robots, servers, aircraft, landscapes, stars, text,
neon, bright cyan, glossy 3D, gradients, and generic corporate vector styling.

### Glyph family

Create six subtle role/status badges as close-up fragments of the dark Scotty
app artwork, arranged in an exact 3 × 2 grid with dark gutters. Use dry gouache
and oil-pastel marks on near-black petrol canvas. The six abstract compositions
are: four brush dashes moving forward; three offset horizontal marks accumulating
upward; a broken imperfect ring; one bright mark with three dim marks held in a
quiet orbit without connectors; two pale marks separated by a deliberate gap
with one muted amber mark; and a sparse terracotta route making one angular turn
beside a bone-white mark. Keep them readable at 48 px. Avoid literal clouds,
network meshes, labels, conventional UI pictograms, neon, glossy 3D, and white
backgrounds.

### Hero

Extend the dark Scotty app artwork into a subtle 16:9 panoramic brand world. Use
a near-black petrol canvas with many tiny irregular bone-white brush signals in
sparse, widely separated currents. Let them recede almost invisibly toward the
upper right and become slightly more legible at the lower right. Add one thin,
broken oxidized-terracotta route that never dominates. Preserve uninterrupted
dark negative space across the left 45 percent for product copy. Keep the result
nocturnal, cool, precise, tactile, asymmetrical, and calm. Avoid literal clouds,
people, robots, conventional network diagrams, stars, landscapes, text, neon,
bright cyan, glossy 3D, and gradients.

# Security policy

## Supported versions

Only the latest release receives security fixes.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/Yeshwanthyk/scotty/security/advisories/new). Include the affected version, impact, reproduction steps, and any suggested fix.

Do not include live credentials. Revoke or rotate any credential that might be exposed.
